- **v3.8.0**（2026-10-27）：用户口径反转 —— 规则 ⑥⑦ 改为「**可改变行为**」「**可引入新依赖**」（用户明示删除原「不改变行为」「不引入新依赖」）

  - **§10.5 判据迁移**：删除「行为改变/新依赖 ⇒ 禁止自动」的推理链，改用四条**独立判据**——**可逆性**（改错能一次回滚）· **语义唯一解**（无「二选一」业务判断）· **发布面不变**（不改公共签名/导出符号/依赖版本约束/lockfile）· **可验证**（有现成手段判定对错）。四条任一不满足 → 出方案不改码

  - **可靠性类不再「例外」**：原「可靠性类是『不改变行为』唯一例外区」表述作废；改为「行为**可以**变，但有意变更必须单列变更点 + 补『没有这次修复就会失败』的测试」

  - **动词词典改口径**：「行为等价性」列改为「行为影响」列（`remove`/`extract`/`parameterize` 通常无变化；`inline`/`simplify`/`merge` 可能变；`replace`/`add`/`guard`/`type_guard` 变）。**行为改变不再是禁行理由**，禁行理由改为「改错不可逆 / 需人判正确语义 / 破坏发布面」
