## 案例 1 · 早停门（P0 触发后不输出优化层）

**输入**（片段模式，无 spec）：

```python
import hashlib

DB_PASSWORD = "Pr0d@2026!x"          # 第 3 行

def save_user(conn, name, pwd):       # 第 5 行
    h = hashlib.md5(pwd.encode()).hexdigest()      # 第 6 行
    conn.execute(f"INSERT INTO users VALUES ('{name}', '{h}')")   # 第 7 行
```

**实测命中集**：`PY-07`(A 模, L3)、`PY-15`(L6)、`PY-14`(L7)；叠加语义判定 `OWASP-A03` 注入、`OWASP-A02` 弱加密存储 → 全部 **P0**。

**预期输出**：
- [ ] 结论行 = `🛑 早停：存在 P0，仅输出阻断报告`
- [ ] **不出现**：维度评分表、CAC、DICE/ROI、技术债清单、修复路线图（阶段 C 被早停门跳过）
- [ ] 健康评分标 `未评估`
- [ ] 每条 P0 必带 6 要素：位置 / 证据（原代码行）/ 影响（业务后果）/ 建议（代码块）/ 规则号 / 置信度=`高`
- [ ] `PY-15` 需注明「`md5` 用于口令散列」才算 P0；若用于非安全校验和（如文件指纹）应降级——审查时要读上下文，不是见 md5 就报

**失败判定**：出现「维度评分表」或「ROI」= 早停门失效。

## 案例 2 · 证据门槛（单引擎命中必须降级）

**输入**（片段模式）：

```python
def load(path):
    with open(path) as f:          # 第 2 行
        return f.read()
```

**实测命中集**：`PY-12`（`open\s*\(` 命中 L2）。

**预期输出**：
- [ ] 命中级别 = **P2**，标注 `置信度=低` 且原文写「待验证假设」
- [ ] **不得**定 P0/P1，**不得**写「根因：资源泄漏」
- [ ] 必须说明降级理由：`with` 已闭合上下文管理器，`open(` 属模式误报
- [ ] 结论行 = `✅ 可批准`（无真实 P0/P1）

**失败判定**：把 `with` 场景报成 P1 资源泄漏 = 证据门槛失效（grep 直击未做语义确认）。

## 案例 3 · 分级呈现（P0/P1 与 P2/P3 不混排）

**输入**（片段模式）：

```python
import os
API = "sk-live-9f8e7d6c5b4a"          # 第 2 行

def get(url):
    return requests.get(url)          # 第 5 行
```

**实测命中集**：`PY-07` **A 模命中**（`api\s*[:=]` 于 `(?i)` 下匹配 `API =`）+ **B 模命中**（`sk-` 前缀）；`PY-10`（`requests.get(` 无 `timeout=`）。

**预期输出**（结构校验，逐条打勾）：
- [ ] `#### 🔴 P0` 段落内**只有** `PY-07` 一条
- [ ] `#### 🟡 P1` 段落**独立存在**，含 `PY-10`
- [ ] `#### 🟢 P2 + 🔵 参考` 段落**独立存在**（可标注「本次无」）
- [ ] 三段落之间**无交叉**：P0 段里不出现 timeout，P2 段里不出现硬编码密钥
- [ ] 注释前缀符合映射：P0=`🚨 issue (blocking):`、P1=`issue (blocking):`、P2=`suggestion:`
- [ ] 至少 1 条 `praise`

**这条是 PY-07 双模规则的活样本**：v3.6 之前 A 模只写 `(password|secret|token|key)`、且大小写敏感，`API = "sk-…"` 完全漏报。若改后本案例 P0 段为空 → PY-07 退化，立即回滚。

## 案例 6 · 标签-动词映射与自动修复边界（v3.7 新增，v3.8 改判据）

**输入**（片段模式，含四类标签各一处）：

```python
import os                       # 第 1 行  → noise/unused_import → remove
from typing import List         # 第 2 行  → noise/unused_import → remove

def wrapper(x):                # 第 4 行  → redundant/redundant_wrapper → inline
    return helper(x)

def helper(x):
    print("debug:", x)         # 第 8 行  → noise/debug_leftover → remove
    return str(x)              # 第 9 行  → redundant/redundant_cast → inline

def long_task(a, b, c, d, e):  # 第 11 行 → structure/long_parameter_list → 只建议
    try:
        conn.execute(f"SELECT {a}")   # 第 13 行 → reliability/unsafe_cast → type_guard
    except Exception:
        pass                    # 第 15 行 → reliability/missing_error_handle → guard
    return requests.get("http://x")   # 第 16 行 → reliability/missing_error_handle → add
```

**预期输出（结构校验，逐条打勾）**：
- [ ] 每条发现带四字段：`级别` + `标签` + `动作`（`remove`/`inline`/`guard`/`add`/`type_guard`/—）+ `行为变化`（无/有）
- [ ] 标签全部落在 24 标签闭集内；动作全部落在 10 动词闭集内（结构类动作为 `—`）
- [ ] **`except: pass` 判为 `missing_error_handle`（可靠性），不得判为 `empty_block`（噪声）** —— §10.9 仲裁第 1 条
- [ ] `print("debug:", x)` 判 `debug_leftover`（噪声 → `remove`），但**不得**据此认定整段无处理逻辑
- [ ] `f"SELECT {a}"` 判 `unsafe_cast` → `type_guard`（可靠性，P0/P1）
- [ ] `long_parameter_list` 判结构类 → **只出建议，不出动词，不改码**
- [ ] **自动修复清单**（判据=可逆性/语义唯一解/发布面不变/可验证，**不是**「会不会改行为」）：
  - 噪声 3 项（`unused_import`×2、`debug_leftover`）→ **可自动**（§10.5 自动列）
  - 冗余 2 项：`redundant_cast` → **可自动**（§10.5 自动列）；`redundant_wrapper` → **需人工确认**（公开 API 边界，§10.5 人工列）
  - 可靠性 3 项按「修法唯一性」分：`missing_error_handle` 的 `except: pass` 补具体异常处理（修法多解 → 人工）、`unsafe_cast` 补显式类型检查（修法唯一 → 可自动）、`hardcoded_secret` 若在片段内（改读环境变量，修法唯一 → 可自动，但属 P0 需走 §B2）
  - 结构类 1 项 → 只建议（§10.5 人工列，不改码）
- [ ] **行为变化声明**：可靠性类若自动执行 → 报告单列「改前行为 → 改后行为」+ 补「没有这次修复就会失败」的测试；不得因「会改行为」而拒绝修复
- [ ] 报告含**双视角**：级别分组（P0/P1 vs P2/P3）+ 标签统计表（5 类）+ 行为变化统计
- [ ] §10.6 四项验证未跑之前，**不得**把修复计入「已修复」计数

**失败判定**：
- `except: pass` 被判成噪声 `empty_block` → §10.9 仲裁失效
- 结构类给出主动词或直接改码 → 「结构→只建议」规则失效
- `redundant_wrapper` 被列入自动执行清单 → §10.5 分桶失效（v3.8：公开 API 边界须人工）
- 可靠性类因「会改行为」被整体排除出自动堆 → §10.5 判据迁移失效（v3.8 前的旧口径）
- 可靠性类自动执行但**未单列变更点、未补测试** → §10.6 声明要求失效
- 只出现级别视角、缺标签统计表 → §10.8 双视角失效
